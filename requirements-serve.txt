# Version note (see 13_deployment/README.md): install fastapi and uvicorn
# together in a clean env. An OLD fastapi (e.g. 0.104) next to a NEW starlette
# (1.x) is incompatible — not even a bare FastAPI() builds
# (Router.__init__() got an unexpected keyword argument 'on_startup'). The
# floor below pulls a modern fastapi whose pinned starlette range is coherent;
# the exact tested pair is recorded in constraints.txt.
